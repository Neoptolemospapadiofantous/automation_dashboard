# Security Policy

## Reporting a Vulnerability

Please **do not** open a public issue for security vulnerabilities.

Report privately through GitHub's
[private vulnerability reporting](https://github.com/Neoptolemospapadiofantous/automation_dashboard/security/advisories/new)
(repository **Security** tab → **Report a vulnerability**), or email
**neoptolemos.papadiofantous@gmail.com**.

Please include steps to reproduce, affected routes/components, and any
proof-of-concept. We aim to acknowledge reports within **3 business days**
and to share a remediation timeline after triage.

## Supported Versions

This application ships as a single rolling release — only the latest
`main` is supported. Security fixes land on `main` and are deployed forward.
