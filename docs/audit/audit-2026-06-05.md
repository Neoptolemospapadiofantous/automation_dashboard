# Codebase Audit & Expansion Proposals — 2026-06-05

> Auto-generated multi-agent audit. 46 confirmed findings (of 56 raw). 1 candidates refuted as false positives during adversarial verify.

## Executive summary

The codebase has accumulated significant Phase-14 cleanup debt: the BYOK product surface was removed but multiple backend endpoints (agents.rotate-secret, agents.health), supporting flash keys, lifecycle states, and at least four orphan Jetstream-era Vue components remain. The most urgent issues are billing-side config drifts — Plan::stripePriceId() and TopUpPack::stripePriceId() read config keys that don't exist (starter/operator/topup_*), so any future Stripe webhook will silently fail to resolve prices, and CreditMeter::grantMonthlyRenewal will wipe Business teams' negotiated balances to 0 when first called. A user-facing regression already ships: the top-up success banner in Billing/Index.vue can never render because 'topup' isn't whitelisted in HandleInertiaRequests's flash array. Several broadcast events (DashboardTick, LeadMessage, the App.Models.User.{id} channel) are dispatched into the void with no Echo subscribers, and the team.{teamId} channel has a presence-vs-private kind mismatch worth fixing. Doc-vs-code drift is widespread (phase-2/3/6/13 docs, integration-map, public-surface), and three new public-stats fields plus the ?lead_id cross-tenant filter ship without test coverage. Multiple schema columns (conversations.meta, conversations.voiceflow_session_key, messages.payload, leads.notes, lead_assignments.previous_assignee) are write-only or completely unused.
