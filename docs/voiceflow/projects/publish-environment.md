# Publish Environment

Base URL: `https://realtime-api.voiceflow.com`

## Path parameters

| Name                            | Type   | Required | Description                                  |
| ------------------------------- | ------ | -------- | -------------------------------------------- |
| `projectID`                     | string | yes      | ID of the project that owns the environment. |
| `projectEnvironmentIDorAlias`   | string | yes      | ID or alias of the environment to publish.   |

## Request body — `application/json`

| Field         | Type           | Required | Notes               |
| ------------- | -------------- | -------- | ------------------- |
| `name`        | string         | yes      | Release name. Min length 1. |
| `description` | string \| null | yes      | Release description.        |

```json
{
  "name": "Release 12 — checkout fixes",
  "description": "Hotfix for cart-abandonment intent"
}
```

## Response — 201 Created

```json
{
  "data": {
    "projectEnvironment": { /* updated ProjectEnvironment, same shape as Get Environment */ },
    "projectEnvironmentRelease": {
      "name": "string",
      "description": "string|null",
      "versionID": "string",
      "backupID": 0,
      "createdAt": "string",
      "autogenerated": false,
      "createdByUserID": 0
    }
  }
}
```

## Authentication

API key in `authorization` header.
