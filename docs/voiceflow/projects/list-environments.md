# List Environments

Base URL: `https://realtime-api.voiceflow.com`

Returns the collection of environment objects for the specified assistant/project.

## Path parameters

| Name        | Type   | Required | Description                            |
| ----------- | ------ | -------- | -------------------------------------- |
| `projectID` | string | yes      | ID of the project that owns the envs. |

## Authentication

API key in the `authorization` header. A regular Voiceflow workspace dialog API key is sufficient (no enterprise/admin scope documented).

## Response — 200 OK

`ProjectEnvironmentListResponse`:

```json
{
  "data": [
    {
      "id": "string",
      "name": "string",
      "alias": "string",
      "isMain": true,
      "releases": [
        {
          "name": "string",
          "backupID": 0,
          "createdAt": "string",
          "versionID": "string",
          "description": "string|null",
          "autogenerated": true,
          "createdByUserID": 0
        }
      ],
      "createdAt": "string",
      "draftVersionID": "string",
      "publishedVersionID": "string",
      "createdByUserID": 0,
      "trafficPercentage": 100,
      "nextReleaseNumber": 1,
      "draftVersionIDsHistory": ["string"]
    }
  ]
}
```

## Notes

- Aliases are first-class identifiers — most other endpoints accept either the environment ID or its alias.
- `trafficPercentage` across all returned environments should sum to 100.
- No rate limits are documented for this endpoint.
