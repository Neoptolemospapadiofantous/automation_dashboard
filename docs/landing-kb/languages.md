# Languages — multilingual chat and language support

The agent replies in **whatever language the visitor writes in**. That is the
whole rule, and it is on by default for every agent on every plan.

A visitor who opens the chat in Greek gets Greek back. The next visitor who
writes in English gets English. Someone writing in German, French or Italian
gets their own language. Nobody configures anything, there is no language
picker for the visitor to find, and you do not run a separate agent per
language.

> The reply follows the visitor's own message — not the language this page, or
> your knowledge base, happens to be written in.

If you are asking whether the widget supports multiple languages, whether the
chat is multilingual or bilingual, whether it handles language support or
translation, or whether it can serve customers who do not write in English:
yes, and this page is the answer.

## Your source material and the reply are separate

Your knowledge base can be written entirely in one language and the agent will
still answer questions asked in another, working from that same material.

Two honest limits:

- The answer is only as good as the material behind it. A question your
  knowledge base does not cover is not solved by translating harder — the
  agent says it does not know and offers a human, in the visitor's language.
- Names, product terms and exact wording stay closest to how you wrote them.
  If specific phrasing matters to you in a particular language — a service
  name, a legal phrase — put that wording in your knowledge base and the agent
  will use it.

## Quick answers

- **Which languages?** Any the visitor is likely to write in. Greek and
  English are both fully supported; so are the other common European ones.
- **Do I need a separate agent per language?** No. One agent handles them all.
- **Does the website widget support this?** Yes — the same widget, the same
  single script tag. Multilingual is not an add-on or a paid extra.
- **Do I have to translate my knowledge base?** No. Add other-language wording
  only where the exact phrasing matters to you.
- **What do transcripts and the leads dashboard show?** The conversation
  exactly as it happened, in the language it happened in.
