# Building your knowledge base

Yes — Flowstack has a built-in knowledge base, and it is how your agent knows
your business. The agent answers visitors only from what you put in it (plus
the conversation itself); it never invents product facts.

## How to add knowledge

In the dashboard, open **Documents** (the Knowledge section). Two ways to add
content, no coding either way:

- **Paste text** — FAQs, policies, product descriptions, price lists, opening
  hours. Each document gets a title and is searchable the moment it saves.
- **Add a page by URL** — paste a public page from your website and Flowstack
  fetches and ingests it.

During onboarding there is a third, automatic way: if you give your website
address, the setup wizard ingests it into the agent's knowledge base for you —
so a brand-new agent answers from your site on day one.

## How it behaves

- Knowledge is **per agent** — each agent answers only from its own documents.
- Changes apply **immediately** — the next visitor message is answered from
  the updated knowledge; there is nothing to redeploy or re-publish.
- Re-adding a changed document **replaces** the old version; it does not
  duplicate.
- When the knowledge base can't answer a question confidently, the agent says
  so and offers a human instead of guessing.

## Knowing what to add next

The Knowledge page also keeps a ranked list of **gaps** — real questions
visitors asked that the knowledge base couldn't answer confidently. Reviewing
that list is the fastest way to grow the knowledge base: add a document that
answers the top gap, mark it resolved, repeat.
